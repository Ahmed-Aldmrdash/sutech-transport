06 · Icons

Lucide, 2px stroke, rounded

One icon set only: Lucide (open-source, matches sut.edu.eg's thin rounded arrows). 20px in lists and buttons, 24px in nav and app bar, colour = currentColor. Flip arrows and chevrons in RTL with .flip.

07 · App icon

PWA icons & splash

Official 3-shape mark on white (the mark is never recoloured). Maskable versions keep the mark inside the 80% safe zone. Files: assets/pwa/.
